# Ұшақпен бұлттар әлеміне саяхат ✈️

1-сынып оқушыларына арналған «Ұұ дыбысы және әрпі» тақырыбын бекітетін интерактивті браузер ойыны.

Ұшақпен ұшып, бұлттардағы сөздерді оқып шығыңыз. Сөзде **Ұ/ұ** әрпі болса, бұлтқа тиіп өтіңіз. Әрпі болмаса, бұлттан жалтарыңыз. Үш өмірді сақтап, мүмкіндігінше көп ұпай жинаңыз.

## Ойын ережесі

- Ұ/ұ бар бұлтқа тисеңіз: +1 ұпай.
- Ұ/ұ жоқ бұлтқа тисеңіз: −1 өмір.
- Ұ/ұ бар бұлттан жалтарсаңыз: −1 өмір.
- Ұ/ұ жоқ бұлттан жалтарсаңыз: ештеңе өзгермейді.
- Ү/ү әрпі Ұ/ұ болып есептелмейді.
- Деңгейлер: 0–7 ұпай — 1-деңгей, 8–17 — 2-деңгей, 18+ — 3-деңгей.

## Басқару

| Құрылғы | Басқару |
|---|---|
| Компьютер | ← → ↑ ↓ пернелері, Space — үзіліс |
| Телефон, планшет, интерактивті тақта | ◀ ▶ батырмаларын басып ұстау, ұшақты саусақпен жоғары-төмен сүйреу |

Дыбыс әдепкіде өшірулі. Оны жоғарғы жақтағы 🔇 батырмасымен қосуға болады.

## Іске қосу

Ойын бір ғана `index.html` файлынан тұрады. Серверді немесе орнатуды қажет етпейді, интернетсіз де ашылады. Файлды браузерде ашсаңыз болғаны.

## GitHub Pages арқылы жариялау

1. Репозиторийдің **Settings → Pages** бөлімін ашыңыз.
2. **Source** ішінен **Deploy from a branch** таңдаңыз.
3. Branch ретінде `main`, папка ретінде `/ (root)` таңдап, **Save** басыңыз.
4. Бірер минуттан кейін ойын `https://<аккаунт>.github.io/<репозиторий-аты>/` мекенжайында ашылады.

## Сөздерді өзгерту

`index.html` ішінде `YES` (Ұ/ұ бар сөздер) және `NO` (Ұ/ұ жоқ сөздер) тізімдері бар. Жаңа сөзді тиісті тізімге қосыңыз. Ұ/ұ әрпін ойынның өзі автоматты түрде анықтайды.

## Файл құрылымы

```
index.html          ойынның толық коды (сурет ішіне енгізілген)
assets/plane.png    ұшақтың фонсыз суреті
assets/background.jpg  ойын фоны (түпнұсқа сапада)
README.md           осы сипаттама
```

`assets` ішіндегі суреттер өңдеуге арналған түпнұсқалар. Ойын оларды ашпайды, өйткені `index.html` ішінде сығылған көшірмелері бар.
